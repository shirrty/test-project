# AGENT.md — LAgent 长期规则

本文件会被 Agent 在会话开始时**整篇注入**一次（作为一条 user 消息），之后每一轮都按这里的约定办事。
想换规则文件位置，可改 `config.ini` 的 `[agent] instructions_file`；想限制注入长度，改 `[agent] max_chars`。

## 一、工具使用约定

- **时间/日期**：一律用 `getDate`，不要自己推算，也不要用 `date`、`time` 之类的命令。
- **实时信息**：先 `searchWeb`（百度千帆智能搜索），不要凭记忆答时效性问题。
- **读网页**：用 `fetchWeb`，不要用 `RunCli` 跑 `Invoke-WebRequest` 或 `curl` 手拼参数。
- **本地命令**：`RunCli` 只传参数列表，不要拼一整个命令行字符串。
- **技能**：不确定某个技能怎么用时先 `loadSkill`；只有用户明确要求新建技能时才 `createSkill`。
- **PPT**：用户要幻灯片时直接调 `makePpt` 传结构化内容，**不要**去读技能目录里那份几千行的模板 HTML。

## 二、回答风格

- 中文回答，先给结论，再给依据；不写"综上所述""希望对你有帮助"这类空话。
- 引用数据要能指到来源（文件路径、批次号、URL），拿不到来源就明说"未核验"。
- 不确定的事不编。工具返回失败时，把真实错误告诉用户，不要换成一句"已完成"。

## 三、文件与路径

- 相对路径一律按当前工作目录解析；写文件前先确认目标目录存在。
- 删除目录前必须回显要删的绝对路径，等用户确认；`delete_dir` 已内置拒绝删除当前工作目录与磁盘根目录。
- 不要在仓库根目录留下运行产物（临时 txt、通知草稿、测试 docx），统一放到 `.agents/tmp/`。

## 四、农产品溯源业务口径

- 批次号格式 `SCYYYYMMDD-NN`；判断放行前必须 `traceBatch` + `auditColdChain` + `checkResidues` 三个工具都跑过。
- 限量值只能引用 `.agents/agri-data/gb2763-limits.json`，不得使用记忆里的 MRL 数字。
- 冷链结论要同时给出"超温累计时长"和"MKT"，只说"有几个点超了"不算结论。
